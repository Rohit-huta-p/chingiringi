The five phases

A

Commission-based coin formula

Every downstream flow depends on this being right. No point wiring Cuelinks/Amazon on top of a wrong model.

  • AdminSettings model: passThroughPercent, coinsPerRupee, defaultLockDays
  • Rewrite importer: coins = commission × passThroughPercent × coinsPerRupee
  • Deal.coinsReward becomes optional promotional override
  • Reports Inbox preview: per-row breakdown (₹ comm → coins → user ₹)
  • New Settings tab with live preview slider

B

User withdrawal flow

Admin side already works. User side is stubbed. Closes the loop.

  • POST /api/wallet/withdraw — user submits coin amount + UPI/bank
  • Server locks in the coinsPerRupee rate at request time on the Transaction
  • Mobile Withdraw Money screen: balance + coin input + live ₹ conversion + UPI form
  • Withdrawal statuses show in existing Transaction History screen

C

Cuelinks + Amazon URL plumbing

Without real credentials wired in, no commission actually earns.

  • Cuelinks: admin pastes raw merchant URL, backend auto-wraps in linksredirect.com template with our publisher ID
  • Amazon: subidBuilder auto-appends tag=<associateTag> for amazon.* hosts
  • CSV parsers hard-code Cuelinks + Amazon column headers (both quirky, worth one-time work)

Days
D

Automation & fallback matching

Eliminates the last bits of manual admin work; rescues subid-stripped rows.

  • Cron confirmExpiredLocks hourly — flips lock-expired pending → confirmed + notifies user
  • Cron staleWithdrawalReminder — pings admin on requests >48h old
  • Click-log fallback matcher: merchant + ±24h + ±5% amount → confidence-scored candidate users
  • Admin review UI for medium-confidence matches

Decide before Day 1

Pass-through %
User's share of every ₹ of commission. Recommend 25%. Growth-aggressive: 40–50%. Cash-conservative: 15–20%.
Conversion rate
10 coins = ₹1 is intuitive. Alt: 100 = ₹1 makes coin numbers "feel bigger" to users. Cosmetic.
Aggregator
Default is Cuelinks. If EarnKaro or Admitad turns out stronger for your merchants, URL template swap is 1 hour later.
Working capital reserve
Users get paid on confirmation, network pays us 30–60 days later. Size ~2 months of expected payouts in the bank.
